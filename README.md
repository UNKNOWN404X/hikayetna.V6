## 🌟 نظرة سريعة على المشروع

تم بناء هذا المشروع بأحدث التقنيات مع الحفاظ على البساطة التامة في الاستخدام:
- **الواجهة:** React 18 + TypeScript + Vite + Tailwind CSS بتصميم سينمائي داكن (Obsidian & Purple).
- **قاعدة البيانات:** Cloud Firestore للمزامنة الفورية بين الهاتفين بدون أي تأخير.
- **التخزين المحلي الآمن:** التطبيق يعمل بكفاءة حتى لو انقطع الإنترنت أو قبل ربط Firebase (عبر الوضع المحلي الذكي).
- **الخصوصية الصارمة:** لا توجد أي مؤشرات قراءة (Seen / Read / Last Viewed / Typing) على الإطلاق.

## 🚀 كيفية تشغيل المشروع وتجربته فوراً (محلياً)

إذا كنت تريد تجربة التطبيق على جهازك الآن:

1. افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع:
   ```bash
   npm run dev
   ```
2. اضغط على الرابط الذي سيظهر لك (عادة: `http://localhost:5173` أو `http://localhost:3000`).
3. ستظهر لك شاشة الدخول:
   - كلمة السر الافتراضية هي: `هنونتي`
4. التطبيق يعمل مباشرة ويحفظ البيانات محلياً حتى قبل ربط Firebase!

## ☁️ خطوات ربط Firebase خطوة بخطوة (بدون خبرة برمجية)

لكي تتزامن البيانات بين جهازك وهاتف الطرف الآخر عبر الإنترنت، اتبع هذه الخطوات البسيطة:

### الخطوة 1: إنشاء مشروع في Firebase
1. اذهب إلى موقع [Firebase Console](https://console.firebase.google.com/) وسجل الدخول بحساب Google.
2. اضغط على **"Add project"** (إضافة مشروع).
3. اكتب اسماً للمشروع (مثلاً: `hikayetna-app`) ثم اضغط **Continue**.
4. يمكنك إلغاء تفعيل Google Analytics ثم الضغط على **Create project**.

### الخطوة 2: إنشاء تطبيق ويب (Web App)
1. بعد إنشاء المشروع، في الصفحة الرئيسية اضغط على أيقونة الويب (`</>`).
2. اكتب اسماً للتطبيق (مثلاً: `hikayetna-web`).
3. اضغط على **Register app**.
4. ستظهر لك شاشة تحتوي على كود به إعدادات `firebaseConfig` تشبه هذا:
   ```javascript
   apiKey: "AIzaSy...",
   authDomain: "hikayetna-app.firebaseapp.com",
   projectId: "hikayetna-app",
   storageBucket: "hikayetna-app.firebasestorage.app",
   messagingSenderId: "123456789",
   appId: "1:123456789:web:abcdef"
   ```

### الخطوة 3: وضع الإعدادات في ملف `.env`
1. في مجلد المشروع، افتح الملف المسمى `.env` (أو انسخ `.env.example` وسمه `.env`).
2. ضع القيم التي نسختها من Firebase أمام كل متغير:
   ```env
   VITE_FIREBASE_API_KEY="هنا apiKey"
   VITE_FIREBASE_AUTH_DOMAIN="هنا authDomain"
   VITE_FIREBASE_PROJECT_ID="هنا projectId"
   VITE_FIREBASE_STORAGE_BUCKET="هنا storageBucket"
   VITE_FIREBASE_MESSAGING_SENDER_ID="هنا messagingSenderId"
   VITE_FIREBASE_APP_ID="هنا appId"
   VITE_DEFAULT_ENTRY_PASS="هنونتي"
   ```
3. احفظ الملف.

### الخطوة 4: تفعيل تسجيل الدخول (Authentication)
1. من القائمة الجانبية في Firebase Console، اضغط على **Build** ثم **Authentication**.
2. اضغط على **Get started**.
3. في تبويب **Sign-in method**، اختر **Email/Password**.
4. فعّل الخيار الأول (Email/Password) واضغط **Save**.
   *(التطبيق يقوم بإنشاء الحساب تلقائياً في أول محاولة تسجيل دخول بكلمة السر).*

### الخطوة 5: تفعيل قاعدة البيانات (Cloud Firestore)
1. من القائمة الجانبية، اضغط على **Build** ثم **Firestore Database**.
2. اضغط على **Create database**.
3. اختر موقع السيرفر الأقرب (مثلاً `eur3` أو أي موقع تريده) ثم اضغط **Next**.
4. اختر **Start in test mode** مؤقتاً أو انسخ القواعد من ملف `firestore.rules` الموجود في المشروع والصقها في تبويب **Rules** لحماية بياناتك.

## 🌐 رفع التطبيق على الإنترنت (Hosting)

### الخيار الأول: النشر عبر Firebase Hosting (الموصى به)
1. قم بتثبيت أدوات Firebase إن لم تكن مثبتة:
   ```bash
   npm install -g firebase-tools
   ```
2. سجل الدخول إلى حسابك:
   ```bash
   firebase login
   ```
3. اربط المشروع:
   ```bash
   firebase use --add
   ```
   (اختر اسم مشروعك الذي أنشأته).
4. ابنِ ملفات الإنتاج وانشر:
   ```bash
   npm run build
   firebase deploy
   ```
5. سيعطيك Firebase رابطاً فورياً (مثال: `https://hikayetna-app.web.app`) يعمل على الهاتف والكمبيوتر فوراً!

### الخيار الثاني: النشر عبر Netlify
1. قم ببناء المشروع:
   ```bash
   npm run build
   ```
2. اسحب مجلد `dist` المولد وأفلته في حسابك على [Netlify Drop](https://app.netlify.com/drop).
3. أضف متغيرات البيئة (`VITE_FIREBASE_...`) في إعدادات الموقع على Netlify.

## 📁 هيكل المشروع

```
ليتل دارك/
├── src/
│   ├── components/      # المكونات المشتركة، الأزرار، القوائم، ويدجت الحالة
│   ├── context/         # إدارة حالة تسجيل الدخول، الأوضاع، والقفل
│   ├── data/            # البيانات الأصلية (الـ 50 سبباً الأصليين المحميين)
│   ├── firebase/        # إعدادات الاتصال بالسحابة والتسجيل
│   ├── pages/           # صفحات التطبيق (النوتات، الرسايل، الفضفضة، الأسباب، إلخ)
│   ├── services/        # دوال حفظ وقراءة وتزامن البيانات
│   ├── styles/          # التنسيقات العامة والرسوم المتحركة
│   └── types/           # تعريفات الأنواع البرمجية
├── firestore.rules      # قواعد أمان السحابة الصارمة
├── firestore.indexes.json # فهارس الاستعلام السريعة
├── firebase.json        # إعدادات النشر على Firebase
├── .env.example         # مثال للمفاتيح المطلوبة
└── index.html           # الصفحة الرئيسية للتطبيق
```

## 🔒 الأمان والنسخ الاحتياطي

- يمكنك في أي وقت الدخول إلى صفحة **الإعدادات** والضغط على **تحميل نسخة احتياطية (JSON)** لتحميل كل النوتات، الرسايل، واللحظات كملف محفوظ على جهازك بأمان.
- في حالة إغلاق التطبيق لمدة 10 دقائق دون حركة، يقفل التطبيق نفسه تلقائياً ويطلب كلمة السر لضمان الخصوصية.
